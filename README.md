## Unit 4: Robot Repair and Projectiles
- Налаштовано префаб снаряда (`Projectile`) з компонентом `Rigidbody 2D` (`Gravity Scale = 0`, `Linear Damping = 0`),
- колайдером-тригером (`Is Trigger`) та матрицею зіткнень шарів (`Layer Collision Matrix`).
- Реалізовано запуск снарядів у `PlayerController.cs` та обробку влучання в `Projectile.cs` через `OnTriggerEnter2D`.
- Допрацьовано скрипт `EnemyController.cs` (додано стан `broken` та метод `Fix()` для зупинки ворога і вимкнення шкоди після лагодження).
- Створено анімацію полагодженого стану `EnemyFixed` та налаштовано перехід в `Animator` за тригером `Fixed`
- без затримки (`Has Exit Time` вимкнено).

   робить його безпечним для персонажа.
